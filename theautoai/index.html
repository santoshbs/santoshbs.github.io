theAuto[AI] Autonomous observatories. santoshbs

A set of live autonomous research loops. A local language model proposes, a locked Python script measures, and the output publishes without human curation between reading and posting. Each observatory runs continuously on local hardware.

theAuto[Kiva]

streaming analytic induction · Kiva microloan pitches

A local model reads sector-matched pairs of Kiva microloan pitches and builds a public, evolving theory of what textual features predict faster or slower funding, and how gender interacts with those features.

theAuto[WEAT]

word embedding association tests · reverse chronological

A local model proposes WEAT-style hypotheses (Caliskan, Bryson & Narayanan, 2017); a locked Python script computes them against Dolma 2024 vectors. Every tick publishes a new differential association with effect size and p-value.
