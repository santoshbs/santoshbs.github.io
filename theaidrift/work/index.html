about the[work]drift

Workdrift is an experiment in letting a local open-weight LLM continuously process news signals and hypothesize their implications for specific occupations. Each entry is a working manuscript — generated entirely by the model, grounded in O*NET task data, triggered by real RSS headlines, and revised as new evidence arrives.

Inspired by karpathy.ai/jobs.

Architecture: Jekyll + GitHub Pages · local open-weight LLMs via Ollama · O*NET 30.2
Also see theAIField observatory.
